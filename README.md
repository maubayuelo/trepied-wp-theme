# Trepied WP Theme

A custom one-page landing WordPress theme for Trépied.

## Description

Minimal, intentional, and conversion-focused WordPress theme designed for clarity and performance.

## Requirements

- WordPress 6.0+
- PHP 8.0+

## Features

- Custom one-page landing design
- Mobile-first responsive layout
- SEO optimized structure
- Multilingual ready
- Tracking support (Meta Pixel, GA4)
- Clean, semantic HTML

## Installation

1. Download the theme
2. Upload to `/wp-content/themes/trepied`
3. Activate the theme in WordPress Admin
