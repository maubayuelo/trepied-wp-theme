
---

## Security Requirements

- Escape all outputs
- Use nonces for form submission
- Validate all input
- Prevent direct file access
- Disable XML-RPC if unused

---

## SEO Requirements

- Proper H1 structure
- Only one H1 per page
- Semantic HTML
- Proper alt text for images
- Meta tags support (compatible with RankMath or Yoast)

---

## Tracking & Analytics

Must support:

- Meta Pixel
- Google Analytics 4

Tracking goals:

- Calendly booking clicks
- Form submissions
- Scroll depth
- CTA button clicks

Events must be easily triggerable via data attributes.
